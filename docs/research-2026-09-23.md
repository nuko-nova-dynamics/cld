# Claude skill refresh: 2026-09-23

## Scope and method

Reviewed the eight cld skills, their references, schemas, runner, and tests against current official documentation. The prior repository history ended with the July 11 refresh against Claude Code 2.1.207. The current installed CLI reports 2.1.280. Research used Firecrawl extracts of Anthropic's pages, with direct page reads and local CLI inspection. Search snippets and model self-reports were not used to establish behavior.

This update targets the agent that calls Claude. Core skills carry operational decisions and invariants; detailed model and API information lives in references. Direct API migration features do not become invented Claude Code flags. The research and runner changes add no dependencies. Installation is a separate release step.

## Validation boundary

Offline tests exercise the runner as a process with a fake Claude binary. Live probes test protocol integration and model availability, not comparative coding intelligence. No claim that one model is the best choice for this user's workloads is justified without representative task evaluations.

The research phase did not replace installed plugin copies. Version 0.3.0 packages this refresh for the shared Nuko Nova marketplace; release and installed-runtime verification are separate from the model probes below. Existing unrelated `.DS_Store` state was preserved.

## Verified results

- All eight skills pass the skill-creator validator; relative Markdown links resolve.
- Eleven offline runner tests pass, including cancellation, forced child cleanup, split UTF-8 decoding, malformed metadata, and malformed/error result handling, missing structured output, array/JSONL terminal selection, permission arguments, truncation, stale artifacts, spawn errors, and invalid limits.
- JavaScript syntax checks, `git diff --check`, and strict Unslop checks pass. Preservation differences were reviewed as intentional changes to outdated instructions, examples, version claims, and source references; the historical changelog remains intact.
- Claude Code 2.1.280 passed plain, schema, and verbose probes with actual `modelUsage` reporting `claude-sonnet-5` at requested low effort.
- Exact-ID structured probes passed for `claude-opus-5-5` at requested medium effort and `claude-fable-5-1` at requested high effort. Each returned the expected verdict in canonical `structured_output` with exit zero.
- The first sandboxed probe failed with `ENOTFOUND` and zero reported usage. Network-enabled probes then succeeded. No model or prompt defect was inferred from that network failure.

The five successful probes reported a combined estimated cost of approximately $0.34. This is CLI accounting, not a provider invoice or a model-quality benchmark. Live probe artifacts are under the temporary `cld-smoke-1KF8Vx`, `cld-lyz78y`, and `cld-MlKiXb` directories returned by the runner.

An independent agent exercised five decision scenarios against the rewritten skills: dirty-repository review, stale retrieval, missing structured output, custom-config resume, and explicit model/effort/budget constraints. It identified a cross-resume budget ambiguity, now corrected: task-wide budgets must be allocated across workers and reduced by prior spend rather than reset on every invocation. This was an instruction-following walkthrough, not an additional live Claude benchmark.
